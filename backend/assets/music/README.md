# Background Music

Place `.mp3` or `.wav` files here. They will appear automatically in the Settings dropdown.

## Recommended royalty-free sources
- https://pixabay.com/music/ (free, no attribution)
- https://freemusicarchive.org (CC licensed)
- https://incompetech.com (Kevin MacLeod, CC-BY)

## Naming convention
`<mood>_<bpm>_<title>.mp3`

Example: `ambient_80_deep_focus.mp3`, `upbeat_120_corporate.mp3`
